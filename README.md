# Vegg Basket Customer App

Vegg Basket is a customer mobile application for browsing products, managing cart and wishlist, placing orders, tracking deliveries, and managing customer profiles.

## Android App

Download the latest Android APK from the Releases section.

## Features

- Customer Login
- OTP Verification
- Product Browsing
- Product Search
- Cart
- Wishlist
- Online Payment / Cash on Delivery
- Order Tracking
- Customer Profile
- Delivery Address
- Notifications
